# Design

The visual source of trainote. The app imports from `src/`, Storybook shows it (`make storybook`), and `project/` is the built copy that the design-system artifact on claude.ai is published from; `docs/design.md` has the flow.

- `src/` is the design system: the components as TSX with `components.css`, a `<Name>.md` guideline beside each, a story per component for Storybook, `tokens.css` generated from `system/tokens.json` (`make tokens`), and `index.ts`, the list of what is published. A component is published when `index.ts` exports it and its guideline and story exist; `scripts/project.ts` fails otherwise.
- `system/` is the rest of the brand: `tokens.json` (Apple's system colors in both themes, the system font at iOS text-style sizes, spacing, radii, with a usage note each), `README.md`, the brand book the artifact opens on, `cover.html`, the cover above it, `fonts/` with Framework7 Icons 5.0.5, the MIT icon font the tab bar uses (the app ships the same file from the npm package), and `components/` with the guideline and the old preview of Bubble and Segmented, which arrive with the Weight graph and the Coach tab.
- `project/` is generated by `make project` and checked by CI (`make project-check`): `components/bundle.js`, one classic script assigning `window.Trainote`, built from `src/index.ts` with React left to the page; `components/bundle.css`; `components/index.d.ts`, the declarations of `src/` in one file; per component its guideline as `README.md` and a `preview.html` written from its stories; and the brand book, the tokens, the fonts and the cover copied from `system/`. Nothing in it is edited by hand. `publish.json` names the artifact it goes to and the canvas that holds a copy.
- `screens/` is the eight iPhone screens as Design Component pages (`*.dc.html`), copied by hand from the canvas artifact (version 1793103344-137b) in 2026-10. Each one mounts the components from the canvas's own copy of the design system (`ds/trainote/`, beside the Design runtime), so they are not standalone HTML. `screens/renders/` is a render of each screen in both themes, made with a local harness around the same files.
