The line above a run of rows: a day, a month, or what the rows are.

Children are the text, set in `footnote` on `secondary-label` with `space-6` above and `space-1` below. On Notes it reads Today, Yesterday, then the weekday and date (Friday, Oct 23); on the all-entries list a month; above the structured preview "Read as 3 entries".

- Do: write it as a plain phrase in sentence case.
- Don't: set it in capitals, add a count in parentheses, or use it as a title; the screen title is the `NavBar`.

Above a run of plain rows use `List`, which carries the header; above the structured preview use `Inset`, which carries its own.
