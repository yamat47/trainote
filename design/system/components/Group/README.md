An inset grouped section of rows, for Profile.

Children are `Row`s and `Field`s. Pass `header` and `footer` text, set in `footnote` on `secondary-label` and inset twice the `margin`; the rows sit in a `grouped-cell` block with `radius-group` on a `grouped-background` page. The last row has no separator.

- Do: group by topic (About you, Goal, Training), one `Group` each, with a `footer` only when a value needs explaining.
- Don't: use a `Group` on Notes, Weight or Coach, which are plain lists; nest groups; write headers in capitals.
